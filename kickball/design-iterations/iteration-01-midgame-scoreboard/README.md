# iteration-01-midgame-scoreboard

This snapshot preserves the current prototype before redesigning the product flow.

## Summary

This version opens directly into a live scoring-style interface. It includes tabs for Score, Lineup, Defense, Stats, and Setup.

## Useful Parts

- Captures many known kickball rules and requirements.
- Includes Liquid Breakfast Club roster data.
- Demonstrates scoring, lineup, defense, and stats as separate areas.
- Provides a concrete artifact for discussing what does not work.

## Main Problem

The prototype feels like the user joined in the middle of a game. On a phone, it asks the user to process too much too soon.

The next prototypes should start from user intent:

- Start a quick game
- Continue a game
- Manage a team
- View player progress
- Score as ump

## Design Verdict

Keep this as a requirements/reference artifact. Do not treat it as the preferred UX direction.
